## 🧱 Стек технологий

- Фреймоврк: Vue 3 + Vite
- UI библиотека: Vuetify
- Язык программирования: TypeScript
- Пакетный менеджер: npm

## 💿 Установка

Используйте npm для установки зависимостей

```bash
npm install
```

## 🚀 Быстрый Старт

```bash
npm install
npm run dev
```

## 🏗️ Сборка

```bash
npm run build
```
